# Фото-портфолио ретушёра (Vue 3 + Vite)

Проект — сайт-портфолио ретушёра с галереей работ

### Основной стек

- **Vue 3** (Composition API, `<script setup>`) — фреймворк для UI
- **TypeScript** — строгая типизация на всех уровнях
- **Vite** — сборщик и dev-сервер
- **Pinia** — управление состоянием
- **Vue Router** — маршрутизация SPA с lazy loading

### Библиотеки

- **@emailjs/browser** — отправка форм обратной связи через EmailJS
- **Cypress** — E2E тестирование
- **Vitest** — unit-тестирование
- **ESLint** + **Prettier** — линтинг и форматирование кода


### Основные директории

- **`src/main.ts`**: точка входа, создание приложения Vue, подключение `Pinia` и роутера.
- **`src/App.vue`**: корневой layout сайта:
  - подключает шапку `SiteHeader`;
  - отображает текущую страницу через `<RouterView />`;
  - навешивает глобальную защиту от контекстного меню и части горячих клавиш сохранения.
- **`src/router/index.ts`**: маршруты приложения.
- **`src/components/layout/SiteHeader.vue`**: шапка + navigation bar.
- **`src/views/*.vue`**: отдельные страницы сайта.
- **`src/stores/gallery.ts`**: `Pinia`‑store для галереи с API интеграцией.
- **`src/api/index.ts`**: API клиент для взаимодействия с backend.
- **`src/components/ProtectedImage.vue`**: компонент для защиты изображений через Canvas.
- **`src/components/ConsultationForm.vue`**: переиспользуемая форма обратной связи.
- **`src/components/BeforeAfterSlider.vue`**: слайдер сравнения "до/после".
- **`env.d.ts`**: типы для `import.meta.env`.


### Админ-панель (`/admin`)

- **JWT аутентификация**
- **Управление альбомами** — создание, редактирование, удаление
- **Загрузка изображений** — множественная загрузка с прогресс-баром
- **Обработка изображений** — автоматическое создание веб-версий и миниатюр

### Защита контента

- **Canvas-рендеринг** — изображения отрисовываются на canvas для защиты от скачивания
- **Блокировка действий** — отключение правого клика, drag & drop, выделения текста
- **Серверная защита** — временные подписанные URL для доступа к изображениям

### Технические особенности

- **Строгая типизация TypeScript**
- **Composition API**
- **Reactive/Ref**
- **Computed properties**
- **Lazy loading**
- **Error handling**
